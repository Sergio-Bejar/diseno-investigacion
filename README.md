## De qué trata el curso

Toda investigación es un conjunto de decisiones, y cada decisión tiene consecuencias para lo que se puede saber. Este seminario enseña a diseñar investigación en ciencia política: formular preguntas, construir argumentos, formar conceptos, y conocer el menú de estrategias empíricas disponibles.

Es el primer semestre de una secuencia de dos. El segundo (Primavera 2027) entra a la inferencia causal formal y a la construcción de la propuesta de tesis.
